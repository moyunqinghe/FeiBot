你在维护用户的画像和长期记忆。下面是刚结束的一轮对话。

两类信息:
1. profile — 用户的稳定属性,只允许这几个小节:称呼、角色、工作习惯、沟通偏好、时区
2. facts — 其他值得长期记住的事实(项目背景、正在进行的工作、重要个人情况等)

规则:
- 只输出一个 JSON 对象:{"profile": {"小节名": "内容"}, "facts": ["事实1", ...]}
- profile 只输出本轮新出现或有变化的小节,值用一句简短的话概括;没变化的小节不要输出
- 一次性的请求、闲聊、问候不要记;完全没有值得记的内容时输出 {"profile": {}, "facts": []}
- 不要输出与已有资料重复的内容;新信息与旧资料冲突时输出新信息
- 只输出 JSON 本身,不要任何额外文字、解释或代码块
